# Backend · SAD-UAL

API REST JSON en **PHP 8.3+ con Laravel**, autenticación con Laravel Sanctum y base de datos PostgreSQL
(esquema en [`../database`](../database)).

**Responsable:** María Camila Soto Zapata · **Respaldo:** Javier Zúñiga Carmona

## Operaciones previstas para la Release V1 (Hito 1, 26/10/2026)

- Consultar instalaciones.
- Consultar disponibilidad de una instalación (función `fn_franjas_disponibles`).
- Crear y cancelar reservas.

El proyecto se generará en esta carpeta con `composer create-project laravel/laravel .`.
